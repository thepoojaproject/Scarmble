# 🔤 Scramble — Word Challenge

A professional responsive Scramble Word Game for Web and Android.

## Features
- 10-round word challenge
- 30-second timer
- Score and streak system
- Hint and skip
- Top 5 persistent high scores
- Save name when qualifying for Top 5
- Mobile-friendly UI
- Android APK via GitHub Actions
- Made in ❤ for Neelam

## GitHub APK
1. Upload this repository to GitHub.
2. Open **Actions**.
3. Select **Build Scramble APK**.
4. Click **Run workflow**.
5. Download the `Scramble-APK` artifact.

## Web
Open `web/index.html` or deploy the `web` folder.
